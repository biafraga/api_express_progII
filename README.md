# API RESTful - Programação Web II

API desenvolvida em Node.js com Express e Sequelize (MySQL) para o gerenciamento de Usuários, Endereços e Contatos. O projeto implementa persistência de dados em banco relacional, sistema de autenticação e rotas documentadas interativamente.

## Tecnologias Utilizadas
* **Node.js & Express:** Servidor e roteamento.
* **Sequelize:** ORM para modelagem e consultas ao banco de dados.
* **MySQL:** Banco de dados relacional.
* **Swagger:** Geração de documentação interativa (UI).
* **Arquitetura:** Padrão em camadas (Controllers, Services, Repositories).
